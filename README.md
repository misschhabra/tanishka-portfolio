# Tanishka Portfolio

A personal portfolio website developed as part of the HTML5 Semantic Structure & Accessibility assignment.

## About the Project

This portfolio website showcases my profile, skills, projects, and contact information. The website is designed with a focus on semantic HTML structure, accessibility, responsiveness, and SEO best practices.

## Features

* Semantic HTML5 structure
* Accessible and user-friendly design
* Responsive layout for mobile, tablet, and desktop
* SEO-friendly implementation
* Multiple pages:

  * Home
  * About
  * Skills
  * Projects
  * Contact

## Technologies Used

* React
* TypeScript
* Vite
* CSS

## Learning Outcomes

Through this project, I learned:

* Semantic HTML5 elements
* Accessibility principles
* Responsive web design
* SEO fundamentals
* Modern frontend development workflow
* Git and GitHub project management
